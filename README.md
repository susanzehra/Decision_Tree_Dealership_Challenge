# Susan Zehra's Decision Tree Dealership Challenge — Lab 15

An interactive, browser-based learning game that teaches decision-tree fundamentals through a vehicle-dealership scenario.

The file `LAB15_CANVAS_TEXT.md` contains the complete Canvas concept review, activity directions, submission requirements, and grading table.

## Features

- Six progressive missions
- Interactive classification and decision activities
- Decision-tree construction and prediction practice
- Training/test data and target-leakage instruction
- Stopping conditions and fallback reasoning
- Final accuracy challenge
- Personalized printable certificate
- Responsive design with no external dependencies
- No data collection or storage

## Run locally

Open `index.html` in a modern browser. For the most consistent behavior, serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save** and wait for GitHub to publish the site.

## Privacy

The student's name is used only in the current browser session to create the completion certificate. It is not saved or transmitted.
